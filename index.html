About WebAudit

MSc Computing project · University of Sunderland

Research context

WebAudit is an accessibility auditing tool I built during my MSc Computing at the University of Sunderland; it later became the basis of my dissertation research. It runs 15 automated checks against WCAG 2.1 Level AA, explains each issue with a suggested fix, and stores every run in MySQL so you can see whether fixes held over time, not just a one-off snapshot.

Tech stack
Frontend: HTML5, CSS3, Vanilla JS, Chart.js
Backend: PHP 8.2 (OOP, PDO)
Database: MySQL 8.0
Crawler: PHP DOMDocument + DOMXPath
Scoring
Starts at 100. Deductions: Critical −20 · Serious −10 · Moderate −5 · Minor −2. Each rule can deduct at most three times its weight, so one repeated mistake cannot wipe out the score. Floored at 0 and stored per run for trend analysis.
Research aim
Automate WCAG 2.1 AA auditing with 15 automated checks across a catalogue of 25 criteria, detect score regressions over time, and evaluate impact on developer remediation speed through a user study.
Limitations
PHP server-side crawling cannot execute JS, so React/Vue SPAs are only partially audited. Contrast checking is heuristic (inline styles only). Dynamic ARIA states are not evaluated.
